# VOX MIXER — Android MVP 0.1

هذه نسخة مصدر أولية قابلة للفتح في Android Studio.

## الموجود حالياً
- واجهة Android بسيطة داكنة.
- طلب إذن المايك.
- التقاط صوت المايك عبر AudioRecord.
- معالجة فورية أساسية بمكسب (Gain) مع محدد قمم (Limiter/soft clipping).
- تشغيل الصوت المعالج محلياً عبر AudioTrack.

## ما ليس موجوداً بعد
- لا يوجد APK جاهز في هذه الحزمة.
- لم يتم بناء/اختبار المشروع على جهاز فعلي هنا.
- لا يوجد حقن صوت إلى TikTok أو Telegram. أندرويد لا يسمح عادةً لتطبيق عادي بأن يصبح ميكروفوناً افتراضياً عاماً لتطبيق آخر؛ يلزم مسار تكامل مدعوم أو عتاد/حل خارجي.
- لا توجد بعد مؤثرات بنت/رجل أو EQ متعدد النطاقات أو خدمة خلفية.

## البناء
1. فك ضغط الملف.
2. افتح مجلد `VOX_MIXER_Android` في Android Studio.
3. دع Gradle ينزل الاعتماديات.
4. شغّل التطبيق على هاتف Android حقيقي ووافق على إذن المايك.
5. وصل سماعة رأس قبل الضغط على تشغيل اختبار المايك.

## ملاحظة
لا تختبر عبر مكبر الهاتف بصوت مرتفع؛ قد يحدث صفير feedback. ارفع الصوت تدريجياً وتوقف إذا شعرت بانزعاج.
